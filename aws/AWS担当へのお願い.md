## 1. このアプリは何をするものか

高齢者見守りPWA「AIホームパートナー」。**朝晩2回、アバターが数問たずねて、
その回答と笑顔の写真から体調の変化を読み取り、心配なときだけご家族のGmailへ知らせます。**

```
[タブレット] おじいちゃん・おばあちゃん
   アバター「昨夜はよく眠れましたか？」
   → 4つの質問に答える
   → 最後に「笑ってくださいね」で写真を1枚
        ↓ ここで初めてクラウドへ1回だけ送信
   AWS ─┬→ Rekognition（写真から笑顔スコアを出す）
        ├→ Bedrock の Claude（回答を読んで体調を総合判断）
        ├→ DynamoDB（結果を記録／写真は保存しない）
        └→ SNS（心配なときだけ）→ [スマホ] ご家族のGmail
```

**日常の雑談は端末の中だけで完結し、クラウドへ送りません。**
クラウドを使うのは1日2回の問診だけです。

## 2. お願いしたい作業（合計2〜3時間）

| # | やること | 所要 | いつ |
|---|---|---|---|
| **0** | **Budgets（お金の見張り）を設定** | 10分 | **最初に必ず** |
| **0.5** | **Bedrock の利用申請** | 10分＋承認待ち | **★今すぐ★** |
| 1 | DynamoDB のテーブルを作る | 10分 | |
| 2 | SNS を作り、ご家族役のGmailを登録 | 15分 | |
| 3 | Lambda を作り、渡したコードを貼る | 60分 | |
| 4 | Function URL（入口）を作る | 15分 | **URLが届いてから** |

### 🚨 なぜ「0.5 を今すぐ」なのか

**Bedrock は AI を使う申請が必要で、承認までに数時間かかることがあります。**
承認待ちの間も他の作業は進められるので、**申請だけ先に出してしまってください。**
ここで待たされると、全体のスケジュールが丸ごとずれます。

### ⚠️ ステップ4だけは「待ち」があります

Function URL の設定には、**アプリの公開URL**（`https://〇〇.github.io` の形）が必要です。
これはフロント担当が用意します。**届くまでステップ4は保留にして、1〜3を先に進めてください。**

## 4. 終わったらフロント担当へ渡すもの

この4つを教えてください。これが揃うとアプリとつながります。

1. **関数URL**（`https://xxxxx.lambda-url.ap-northeast-1.on.aws/` の形）
2. **APP_KEY の値**（自分で決めた合言葉）
3. **ADMIN_KEY の値**（もう1つの合言葉）
4. **BEDROCK_MODEL_ID の値**（Bedrockの画面からコピーしたモデルID）

## 5. とくに気をつけてほしい5つ

### ① リージョンは必ず「東京」
画面**右上**の選択欄です。ここが違うと「作ったはずのものが見つからない」状態になります。**AWSで一番多い事故**です。

### ② SNSは登録しただけでは届きません
メールアドレスを登録すると確認メールが来ます。**その中のリンクをクリックするまで、1通も届きません。**
迷惑メールフォルダも必ず確認してください。

### ③ BedrockのモデルIDは「画面からコピー」
推測で入力しないでください。新しめのモデルは `apac.anthropic.claude-...` のような
**地域名で始まるID**を要求することがあり、間違えるとエラーになります。

### ④ CORSの設定は「オリジンだけ」
| | |
|---|---|
| ✅ 正しい | `https://yuusuke.github.io` |
| ❌ 間違い | `https://yuusuke.github.io/ai-home-partner-app/` ← パスを含めない |

これを間違えると、**Lambdaのテストでは成功するのにアプリからだけ動きません。**原因が分かりにくい罠です。

### ⑤ 届いたメールの文面を目で確認してください
テストで届いたメールに、次の言葉が入っていないか確認してください。

> **うつ / 認知症 / 診断 / 疑い / 異常 / 判定 / 病気 / 症状**

このアプリは医療機器ではないため、**病名や診断を述べてはいけません**（薬機法上の要請です）。
AIが文章を作るので、プログラム側で二重にチェックしていますが、実物の確認をお願いします。
**もし入っていたらすぐ連絡してください。**

## 6. お金について

**この構成の想定費用は、コンテスト期間の合計で100〜300円程度です。**

| サービス | 費用 |
|---|---|
| Lambda / DynamoDB / SNS | **¥0**（無料枠内。しかも期間無制限の枠） |
| Rekognition | **¥0**（12ヶ月の無料枠内） |
| **Bedrock（AI判定）** | **1回あたり約0.25円**。実運用は1日2回なので年間200円ほど |

**⚠️ Budgets は「知らせるだけ」で支払いを止めません。**
実際に使いすぎを止めるのは、Lambdaの環境変数 `DAILY_LIMIT_ANALYSIS`（1日100回）です。
これが1日の上限を約27円に固定します。**この設定を消さないでください。**

## 7. 詰まったときは

**自力で解決しようとせず、フロント担当に連絡してください。** とくに次の場合は必ず連絡を。

- `Cannot find package '@aws-sdk/...'` というエラーが出た
  → Lambdaに入っているSDKの問題です。別のやり方に切り替える手順を用意します
- Bedrockの申請が承認されない／時間がかかっている
  → 判定方法を別のサービスに切り替える判断が必要になります
- メールの文面に上記の禁止語が入っていた

エラーが出た画面のスクリーンショットを撮って共有していただけると早く解決できます。

## 8. コンテストが終わったら

**Function URL（入口）を削除してください。**
認証なしで公開されている入口なので、使い終わったら閉じるのが安全です。
カレンダーに入れておくことをおすすめします。
