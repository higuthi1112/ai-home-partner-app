## お願い① IAM に Polly の権限を追加する

**すでに追加済みでしたら、この作業は飛ばしてください。**

### やること

1. Lambda の画面 → **設定** → **アクセス権限**
2. 「実行ロール」のロール名をクリック（IAM の画面が開きます）
3. 付いているポリシーを**編集**し、次の項目を追加する

```json
{
  "Sid": "PollySynthesizeSpeech",
  "Effect": "Allow",
  "Action": ["polly:SynthesizeSpeech"],
  "Resource": "*"
}
```

リポジトリの [`aws/iam-policy.json`](iam-policy.json) が更新済みなので、
**中身をまるごと貼り替えていただいても構いません**（他の権限も入っています）。

## お願い② Lambda のコードを貼り直す

### やること

1. **[こちらのリンク](https://raw.githubusercontent.com/higuthi1112/ai-home-partner-app/main/aws/index.mjs)** を開く
2. **Ctrl + A** で全選択 → **Ctrl + C** でコピー
3. Lambda のコード画面に貼り付け（**Ctrl + A で全部消してから**）
4. **「Deploy」ボタン**を押す

### 環境変数について

**追加は不要です。** 声は `Tomoko`、エンジンは `neural` をコードの既定値にしてあります。

もし別の声に変えたくなったら環境変数で差し替えられます
（`POLLY_VOICE` / `POLLY_ENGINE`）。いまは設定しなくて大丈夫です。

### 終わったあとの確認

Lambda の「テスト」で、次を実行してください。

```json
{
  "body": "{\"appKey\":\"（APP_KEYの値）\",\"userId\":\"elder-001\",\"action\":\"speak\",\"text\":\"おはようございます。よく眠れましたか。\"}"
}
```

| 返ってきたもの | 意味 |
|---|---|
| `ok: true` ＋ 長い `audioBase64` | ✅ 成功 |
| `音声を作れませんでした` | IAM の権限が足りない可能性大（お願い①をご確認ください） |
| `不明な action です` | 貼り付けがうまくいっていません |

## 補足：うまくいかなくてもアプリは壊れません

読み上げは**3段構え**にしてあります。

1. クラウドの音声（Polly）
2. 失敗・遅延したら → **端末に内蔵されている読み上げ**
3. （2まで落ちれば必ず声は出るので、無音にはなりません）

つまり **Polly が動かなくても、アプリはこれまでどおり動きます。** 急がなくて大丈夫です。

また、`@aws-sdk/client-polly` が Lambda に入っていなかった場合に備え、
**読み込みに失敗しても他の機能（問診・雑談・通知）が止まらない**書き方にしてあります。
