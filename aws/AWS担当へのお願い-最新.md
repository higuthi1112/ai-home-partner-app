## お願い① Lambda のコードを貼り直す（★必須★）

### やること

1. リポジトリの **[`aws/index.mjs`](index.mjs)** を開く
2. **中身をすべて**コピー（Ctrl+A → Ctrl+C）
3. Lambda のコード画面に貼り付け（全部消してから貼る）
4. **「Deploy」ボタン**を押す

### 変更や追加が要らないもの（安心してください）

- ❌ 環境変数の追加・変更 … **一切不要**
- ❌ IAM（権限）の変更 … **一切不要**
- ❌ 新しいAWSサービス … **一切不要**（S3などは使いません）
- ❌ タイムアウトやメモリの設定変更 … **不要**

**コードを差し替えるだけ**で動きます。

### 今回増えたもの（前回からの差分）

| 追加した機能 | 中身 |
|---|---|
| `followUp` という新しい動作 | 問診の1問目の回答をもとに、AIが**追加の質問を1つ作る**ための窓口 |

前回貼っていただいたぶん（写真の7日保存・`getPhoto`・8種類の表情・ご様子の文章）は
**そのまま入っています**。今回は、そこに1つ足しただけです。

### 終わったあとの確認（1つだけ）

Lambda の「テスト」で、次の内容を実行してください（新しいテストイベントを作ってOKです）。

```json
{
  "body": "{\"appKey\":\"（APP_KEYの値）\",\"userId\":\"elder-001\",\"action\":\"followUp\",\"question\":\"昨夜はよく眠れましたか？\",\"answer\":\"腰が痛くて眠れませんでした\"}"
}
```

**腰か眠りについて聞き返す短い質問**が返ってくれば成功です。
（例:「腰の痛みは、いつ頃から続いていますか？」）

`不明な action です` と出たら、貼り付けがうまくいっていません。もう一度お願いします。
